如果想在共享盘中使用wsl的repo：
- 打开 WSL 终端，输入以下命令编辑配置文件：
    ```
    sudo nano /etc/wsl.conf
    ```
- 如果文件是空的，或者已有内容，请**确保**包含以下内容（如果已有 `[automount]`，只修改下面的参数）：
    ```
    [automount]
    enabled = true
    root = /mnt/
    options = "metadata,umask=22,fmask=11"
    ```
